# 🌐 Mobile Network & Diagnostic Dashboard

A lightweight, dark-mode web application designed to instantly display real-time network diagnostics, signal metrics, public IP details, and internet performance directly on mobile devices and desktop browsers.

---

## ✨ Features

* **⚡ Connection Type & Speed:** Automatically detects network generations (4G, 5G, Wi-Fi) and estimates download speed in Mbps.
* **⏱️ Latency & Ping Monitor:** Measures real-time round-trip latency to evaluate internet quality (Excellent, Fair, or Poor).
* **📍 Public IP & ISP Lookup:** Fetches the public IP address along with the active Internet Service Provider (ISP) and geographical location.
* **🟢 Device Online Status:** Displays live connection connectivity state.
* **📱 Mobile-First Design:** Fully responsive dark-mode layout optimized for mobile screens and web browsers.

## 🛠️ How to Use This Project

1. Open the **Live Demo** link on any phone or computer browser.
2. The dashboard will automatically run a initial scan upon opening.
3. Tap the green **"Refresh Network Data"** button at any time to update your live network metrics.

---

## 💻 Technical Details

This project is built using pure, client-side web technologies:
* **HTML5:** Semantic structure and container layouts.
* **CSS3:** Custom responsive dark-theme styling.
* **JavaScript (Vanilla):** Utilizes standard web APIs (`navigator.connection`, WebRTC, Fetch API) to gather telemetry without requiring server installation.
